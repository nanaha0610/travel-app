# 旅行を動画一覧で公開する

動画ファイルは結合しません。旅行を1つのカードとして公開し、撮影順に短い動画を連続再生します。

- 作成ページ／マイページの「この旅行の公開設定」で、許可チェックを入れて公開します。
- 公開すると、旅行名、全ての保存済み動画、撮影日時、訪問場所がログインなしでも閲覧可能になります。
- 非公開の旅行は本人のマイページで見られます。初期状態は非公開です。
- 「自分だけ」にすると旅行公開と、その旅行の全ての個別スポット公開を解除します。
- 動画を追加した場合、旅行の公開を解除します。再度の許可なしでは新しい動画を旅行一覧に公開しません。個別スポットの公開は従来どおり各動画の許可に従います。
- 訪問順は撮影日時の日本時間の日付で分けます。連続する同じ場所だけをまとめ、運河→梅里→運河のような再訪は残します。撮影していない訪問場所は表示されません。

DBの構造変更はありません。既存 trips.status の draft / published を使います。APIサーバーを再起動すると有効になります。

API: POST /api/trips/:tripId/visibility {isPublic: boolean}（本人のみ）
公開取得: GET /api/public/trips、GET /api/public/trips/:tripId/videos、GET /api/public/trips/:tripId/videos/:videoId/content。
旅行一覧は20件ずつ、beforeに最終IDを指定して続きます。非公開に戻った旅行の動画の新規取得は拒否します。既に取得された動画は回収できません。

実DB検証: serverで node --env-file=.env scripts/check-trip-sharing.mjs。一時データは全てロールバックされます。
